# Hosting for BOA

Hosting is the set of Drupal modules behind the Ægir control panel as BOA ships
it: sites, platforms, servers, clients and the task queue that hands work to
Provision, the backend. BOA installs and upgrades it as part of each control
panel; it is not installed on its own.

This repository is the omega8cc fork, developed together with BOA. Documentation:

- [The control panel's modules](https://docs.boa.io/developing/aegir-apis/hosting-module-suite)
- [The Hosting API](https://docs.boa.io/developing/aegir-apis/hosting-api)
- [The fork model and branches](https://docs.boa.io/developing/overview/fork-model)
- [Contributing](https://docs.boa.io/developing/contributing/contributing)

Report problems in the [BOA issue queue](https://github.com/omega8cc/boa/issues),
and security issues as SECURITY.md describes.

Hosting began as part of Ægir 3, from which this fork descends.
